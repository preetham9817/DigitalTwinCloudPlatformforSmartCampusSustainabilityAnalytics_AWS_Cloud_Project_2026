# Dataset

This folder contains the datasets used in the **Digital Twin Cloud Platform for Smart Campus Sustainability Analytics**.

## Files

### 1. campus_sensor_data.csv
A simulated IoT sensor dataset containing real-time smart campus data including:
- Timestamp
- Building ID
- Energy Consumption
- Water Consumption
- Temperature
- Humidity
- CO₂ Level
- Occupancy
- Sustainability Score

### 2. dataset_description.md
Documentation describing the dataset structure, source, storage, and purpose.

## Dataset Type

- Structured CSV Dataset
- Simulated IoT Sensor Data

## Cloud Storage

- Amazon S3
- Amazon RDS (MySQL)

## Purpose

- Monitor campus energy consumption
- Monitor water usage
- Environmental monitoring
- Digital Twin visualization
- Sustainability analytics
- Predictive analysis
- Resource optimization
