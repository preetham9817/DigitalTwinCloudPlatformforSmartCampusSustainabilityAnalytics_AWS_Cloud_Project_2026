# AWS Deployment Guide

## Project Name

**Digital Twin Cloud Platform for Smart Campus Sustainability Analytics**

---

## AWS Services Used

- AWS IoT Core
- AWS Lambda
- Amazon RDS (MySQL)
- Amazon S3
- AWS IoT TwinMaker
- Amazon SageMaker
- Amazon QuickSight
- Amazon Cognito
- AWS Identity and Access Management (IAM)
- Amazon Simple Notification Service (SNS)
- Amazon CloudWatch

---

## Deployment Workflow

1. IoT sensors collect real-time campus resource data.
2. AWS IoT Core receives and securely manages sensor data.
3. AWS Lambda validates and processes incoming data.
4. Amazon RDS stores structured sensor information.
5. Amazon S3 stores historical datasets and backup files.
6. AWS IoT TwinMaker creates the virtual Digital Twin of the campus.
7. Amazon SageMaker performs predictive analytics and forecasting.
8. Amazon QuickSight generates interactive dashboards and reports.
9. Amazon SNS sends notifications and alerts for abnormal resource usage.
10. Amazon CloudWatch monitors application performance and AWS resources.

---

## Expected Outcome

The deployed platform enables real-time sustainability monitoring, Digital Twin visualization, predictive analytics, automated alerts, and intelligent resource optimization for smart campus management.
